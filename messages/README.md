# messages/th.json — คลังประโยคสรุปแบบพูด

ประโยคทั้งหมดที่ Alpha พูดในหน้าสรุป (และส่งให้ Siri / เสียงในเครื่อง) อยู่ที่ `th.json` ไฟล์เดียว
แต่งประโยคที่ `speech.js` (hub) จากข้อมูลดิบ `facts` ที่ finance-app / fuel-logger ส่งมา แอปไม่ส่งประโยค

- `heads` = หัว ใส่ครั้งเดียวตอนต้นสรุป (ไม่ใส่ถ้าประโยคแรกขึ้นต้นด้วย "บอส…" หรือ "สวัสดี")
- `tails` = ท้าย ใส่ครั้งเดียวตอนจบ (ไม่ใส่ถ้าประโยคสุดท้ายมี "สู้ๆ" หรือ "วันที่ดี")
- `messages[key]` = รายการประโยคเต็มของสถานการณ์นั้น สุ่มมา 1 ประโยค (วันเดียวกันได้ประโยคเดิม · ไม่ซ้ำกับ 5 ครั้งล่าสุด)
- ตัวแปรเขียนเป็น `{ชื่อ}` ตัวเลขปัดเป็นจำนวนเต็มก่อนใส่ · ตัวแปรไหนไม่มีค่า หัวข้อนั้นจะถูกข้าม
- เพิ่มประโยคได้โดยต่อท้ายใน key เดิม ไม่ต้องแก้โค้ด

ลำดับการพูด: ค่ากิน (+วันเงินเดือนเข้า) → ค่างวด → รถ → เรื่องอื่นๆ · ถ้าไม่มีอะไรเลยและค่ากินระดับ A ใช้ `nothing` ประโยคเดียว

## รถ (เรื่องที่นับเป็นวัน: 0 = `-today` · 1 = `-tomorrow` · 2–14 = key ปกติ · > 14 ไม่พูด · เลยกำหนด = `-late`)

| key | สถานการณ์ | ตัวแปร |
|---|---|---|
| `car-fuel-low` | น้ำมันเหลือไม่ถึง 15% ของระยะต่อถัง | kmPerL |
| `car-service-km-near` | เช็กระยะตามกิโล ใกล้ถึง (< 1,000 กม.) | leftKm |
| `car-service-km-late` | เช็กระยะตามกิโล เลยแล้ว | overKm |
| `car-service-days` / `-tomorrow` / `-today` / `-late` | เช็กระยะตามวัน | days / – / – / lateDays |
| `car-service-appt` / `-tomorrow` / `-today` | มีนัดเช็กระยะ | days / – / – |
| `car-renew` / `-tomorrow` / `-today` / `-late` | ต่อภาษี / ต่อประกัน / พ.ร.บ. | name, days / name / name / name, lateDays |

`{name}` ของเรื่องต่ออายุ: ภาษี = "ต่อภาษี" · ประกัน = "ต่อประกัน" · พ.ร.บ. = "พอรอบอ" (กัน Siri อ่านจุดแปลกๆ)

## แซว (วันละไม่เกิน 1 ครั้ง · เฉพาะเมื่ออารมณ์อยู่ระดับ โอเค/แนะนำ หรือต่ำกว่า · พูดต่อท้ายสรุปก่อนส่วน "ท้าย")

| key | สถานการณ์ | ตัวแปร |
|---|---|---|
| `tease-late-night` | เปิดหน้าสรุปช่วง 02:30–05:59 | – |
| `tease-repeat` | กดฟังสรุปรอบที่ 3 ขึ้นไปในวันเดียวกัน (ไม่ใช้ seed วันที่) | count |
| `tease-low-spend` | เมื่อวานใช้ค่ากิน > 0 แต่ไม่ถึงครึ่งของแผนต่อวัน (~107 บาท) | yesterday |

## อารมณ์ตัวละครตามสรุป (alpha-face.js)

ถ้าเข้าหลายเงื่อนไข แสดงอารมณ์ที่ลำดับสูงสุด:
**ขอโทษ > เป็นห่วง > ขอขัด > ไม่เห็นด้วย/งอน > ไม่แน่ใจ > โอเค/แนะนำ > แซว > ทักทาย**

| อารมณ์ | เมื่อไหร่ |
|---|---|
| ขอโทษ | โหลดข้อมูลไม่ได้เลยสักแอป (สรุปจากข้อมูลล่าสุดที่จำไว้) |
| เป็นห่วง | เรื่องรถเลยกำหนด · ค่ากินระดับ F |
| ขอขัด | มีเรื่องครบกำหนดวันนี้ (ค่างวด / เช็กระยะ / นัดศูนย์ / ต่อภาษี ประกัน พ.ร.บ.) |
| ไม่เห็นด้วย | ค่ากิน C/D · วันเงินเดือนเข้าแต่รอบที่แล้วเกินงบ |
| งอน | ค่ากิน E |
| ไม่แน่ใจ | มีประโยค uncertain-* ในสรุป · ช่องสั่งงานแกะคำสั่งไม่ออก (ชั่วคราวระหว่างคำตอบขึ้น) |
| โอเค / แนะนำ | ค่ากิน A / B |
| แซว | มีประโยคแซวในสรุป |
| ทักทาย | ไม่มีอะไรเลย · ยังไม่มีข้อมูล |
| ทำงาน | หน้าซิงก์ |
